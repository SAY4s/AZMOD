# 🎓 آزمود (Azmood) | پلتفرم ساخت و برگزاری آنلاین آزمون

**آزمود** یک پلتفرم آنلاین برای طراحی، اشتراک‌گذاری و برگزاری آزمون است که آموزشگاه‌ها، مدرسه‌ها و سازمان‌ها می‌توانند بدون نیاز به دانش فنی، در چند دقیقه یک آزمون بسازند، لینک اختصاصی آن را برای شرکت‌کنندگان ارسال کنند و نتایج را به‌صورت لحظه‌ای دریافت کنند.

این پروژه به‌صورت **کاملاً سمت کلاینت (Frontend-only)** با HTML، Tailwind CSS و جاوااسکریپت خالص پیاده‌سازی شده و از **Firebase** (Authentication + Firestore) به‌عنوان بک‌اند بدون سرور (Serverless) استفاده می‌کند.

🔗 دمو: [say4s.github.io/AZMOD](https://say4s.github.io/AZMOD/)

---

## ✨ امکانات

- 🖥️ **لندینگ‌پیج حرفه‌ای** با معرفی محصول، نحوه‌ی کار، ویژگی‌ها، تعرفه‌ها و درباره‌ی ما
- 🔐 **احراز هویت کاربران** (ورود / ثبت‌نام) با ایمیل و رمز عبور از طریق Firebase Authentication
- 🧩 **ساخت آزمون سفارشی** با انواع سوالات: تک‌گزینه‌ای (`single`)، چندگزینه‌ای با چند پاسخ صحیح (`multiple`) و پشتیبانی از تصویر برای سوال و گزینه‌ها
- ⏱️ **تنظیمات آزمون**: محدودیت زمانی، به‌هم‌ریختن ترتیب سوالات (`shuffleQuestions`)، نوع نمایش نتیجه (`resultDisplay`)
- 🔒 **کنترل دسترسی**: امکان محدودسازی شرکت در آزمون به فهرستی از کدهای ملی مجاز (`access.allowedIds`)
- 💳 **پلن‌های قیمتی متنوع** بر اساس تعداد شرکت‌کننده (از رایگان تا سازمانی/سفارشی)
- 🎯 **آزمون‌های آماده‌ی ملی/عمومی** برای تمرین بدون نیاز به ساخت حساب کاربری (بارگذاری خودکار از Firestore)
- 📊 **ثبت و مشاهده‌ی نتایج**: نمره، درصد قبولی/مردودی، مدت‌زمان پاسخ‌گویی و ریز پاسخ‌های هر شرکت‌کننده
- 📱 **طراحی واکنش‌گرا و راست‌به‌چپ (RTL)** با فونت وزیرمتن (Vazirmatn)

## 🧬 ساختار داده‌ی یک آزمون (Firestore Schema)

هر آزمون به‌صورت یک سند (Document) در Firestore ذخیره می‌شود. نمونه‌ی کامل آن در فایل [`sample-exam-schema.json`](./sample-exam-schema.json) قرار دارد. خلاصه‌ی فیلدهای اصلی:

| فیلد | توضیح |
|---|---|
| `examId` | شناسه‌ی یکتای آزمون |
| `title` / `description` | عنوان و توضیحات آزمون |
| `settings.timeLimitMinutes` | مدت‌زمان مجاز آزمون (دقیقه) |
| `settings.shuffleQuestions` | به‌هم‌ریختن تصادفی ترتیب سوالات |
| `settings.access.mode` | نوع دسترسی (`restricted` یا عمومی) |
| `settings.access.allowedIds` | فهرست کدهای ملی مجاز برای شرکت (در حالت محدود) |
| `plan.tier` / `plan.userLimit` | پلن خریداری‌شده و سقف تعداد شرکت‌کننده |
| `questions[]` | آرایه‌ی سوالات؛ هرکدام شامل `type`، `text`، `image` و `options[]` |
| `results[]` | نتایج ثبت‌شده‌ی شرکت‌کنندگان شامل نمره، وضعیت قبولی و ریز پاسخ‌ها |

## 🚀 راه‌اندازی

### پیش‌نیاز: ساخت پروژه‌ی Firebase

از آنجا که آزمود از Firebase برای احراز هویت و ذخیره‌ی داده استفاده می‌کند، پیش از اجرا باید یک پروژه‌ی Firebase بسازید:

1. یک پروژه در [Firebase Console](https://console.firebase.google.com/) بسازید.
2. سرویس **Authentication** را فعال کرده و روش ورود «ایمیل/رمز عبور» را روشن کنید.
3. سرویس **Cloud Firestore** را فعال کنید و کالکشن `exams` را (بر اساس فرمت `sample-exam-schema.json`) ایجاد کنید.
4. از بخش **Project Settings → Your apps**، مقادیر `firebaseConfig` پروژه‌ی خود را کپی کرده و در انتهای فایل‌های `index.html` و `login.html` (بخش `CONFIG`) جایگزین کنید.

### اجرای محلی

```bash
git clone https://github.com/SAY4s/AZMOD.git
cd AZMOD

# اجرا با یک سرور استاتیک ساده
python3 -m http.server 8000
# یا
npx serve .
```

سپس مرورگر را باز کرده و به آدرس `http://localhost:8000` بروید.

## ⚠️ نکته‌ی امنیتی

مقادیر `firebaseConfig` موجود در کد (شامل `apiKey`) مربوط به پروژه‌ی نمایشی توسعه‌دهنده هستند. کلید API فایربیس ذاتاً محرمانه نیست، اما **قوانین امنیتی Firestore و Authentication** (Security Rules) باید به‌درستی تنظیم شوند تا از دسترسی غیرمجاز به داده‌های آزمون‌ها و نتایج جلوگیری شود. پیش از استفاده‌ی عملیاتی، حتماً Security Rules مخصوص پروژه‌ی خودتان را پیکربندی کنید.
